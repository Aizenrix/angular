# Результаты проверки

Проверено 20 ноября 2026 года.

| Проверка | Результат |
|---|---|
| TypeScript и сборка Vite | `npm run build` прошла |
| Линтер | `npm run lint` прошла без ошибок и предупреждений |
| Автоматические тесты | `npm test` прошла, 16 тестов формы, хранения, HTTP и контракта workflow |
| Доска в браузере | Пять стартовых заявок, создание и очистка формы, срочность, раскрытие подробностей, возврат и смена статусов, поиск, удаление и сохранение после перезагрузки |
| Production webhook в n8n 2.45.4 | Заявка из браузера прошла три узла. Тестовый Bot API получил комнату, категорию, статус и срочность. Символы `<`, `>` и `&` экранировались |
| Отказ тестового Bot API | Вкладка Executions показала ошибку. Вебхук вернул HTTP 500. Заявка осталась на доске |
| Остановка и повторный запуск | При отключённом n8n заявка сохранилась. После запуска новое уведомление снова дошло до бота в Telegram. Старая заявка повторно не отправилась |
| Docker Compose | Контейнер `n8nio/n8n:2.45.4` запущен через Compose. Проверены `docker compose stop`, `docker compose start` и готовность вебхука после повторного запуска |
| Реальный Telegram | Бот @angular7372_bot получил заявку с доски и доставил сообщение о комнате 216Б в личный чат. В сообщении видны категория «Электрика», «Статус: Новая» и «Срочно: да». Обе доставки, включая контроль после запуска контейнера, имеют статус `success` в истории n8n |
