# Протокол проверки

Вариант «Общежитие», 20 ноября 2026 года. В качестве основы использована собранная в модуле 1 доска. Отдельный личный исходник после главы 2.5 отсутствовал.

| Проверка | Результат |
|---|---|
| Сборка и линтер | `npm run build` и `npm run lint` прошли |
| Автоматические тесты | 13 тестов формы, объединения событий и сценариев n8n, 3 интеграционных теста правил PocketBase |
| Миграция PocketBase | Создана коллекция `obshchezhitie` с четырьмя категориями и пятью записями |
| Остановка базы | После остановки контейнера и обновления страницы появилась кнопка «Повторить». После запуска повтор восстановил список |
| Две вкладки | Запись из первой вкладки появилась ровно один раз в каждой. Категория и срочность после ответа модели обновились по SSE |
| Опрос и подписка | В одном минутном интервале после загрузки опрос сделал 6 GET списка, SSE не сделал ни одного. Измерение по журналу PocketBase, без запросов начальной загрузки |
| ИИ-диспетчер | Реальная цепочка прошла через Ollama, n8n и Telegram. Ошибочная «Мебель» поменялась на «Электрика», затем n8n сохранил признак срочности и отправил кнопку |
| Классификация на выборке | Первоначальная инструкция дала 5/6 по категории и 5/6 по срочности. После уточнения критериев и добавления примеров — 6/6 и 6/6. Подробности в [PROVERKA-MODELI.md](PROVERKA-MODELI.md) |
| Кнопка «Взять» | В заявке комнаты 216Б реальное нажатие изменило сообщение, убрало кнопку и записало имя мастера. Обе вкладки показали «В работе» без F5 |
| Секреты | Значения токена, ID чата и пароль суперпользователя не входят в исходники и выгрузки |
